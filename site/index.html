The same homepage, 27 years apart.

Everything on the 1999 page works. The counter counts, the guestbook takes entries, and the modem you heard was built by your browser while you listened. There's no server behind any of it, just files on GitHub Pages. Here's what each piece turned into, with the code from both years.

01

The modem

    Everyone online in 1999 heard this, and almost nobody knew what it was. Two modems were testing the phone line: which frequencies got through, how bad the echo was, how fast they could push. Your browser built the whole thing from the ITU specs, sample by sample, and ran its own FFT over it to draw the picture above. Time runs left to right, pitch goes up, and brighter means louder.

    02

    Hit counter

    ------

    waiting for the counter

    In 1999 the number changed when you pressed reload. Now it changes on its own. The page holds a stream open to a counting API, and every new visitor gets pushed to everyone with the page open. Open a second tab and watch this one.

    03

    Guestbook

    1. Loading entries...
    Sign it on GitHub

    The 1999 script pasted whatever you typed straight into the page, so people typed <script>. Then the casino bots found it. Now the guestbook is a GitHub issue. Signing needs an account, which stops most spam, and the page reads the comments with one public API call and puts them on screen as plain text, never HTML.

    04

    Last updated

    local copy, never deployed

    In 1999 you dragged index.html into the right pane of WS_FTP and hoped nobody loaded the page halfway through. The date at the bottom was whatever the server said the file's timestamp was. Now every push to main runs the tests, stamps the commit into the page and publishes it. The line above comes from that stamp.

    05

    Page weight

    On a 56K modem every kilobyte cost the visitor about a fifth of a second, so you counted them. Netscape even had LOWSRC, a tiny black-and-white image it showed while the real one crawled in. Nobody counts anymore. The median home page in 2025 was 2,164 KB, which is over seven minutes of the sound you heard at the start.

    06

    Work offline

    checking...

    In 1999 you were offline most of the day, and you paid by the minute when you weren't. Internet Explorer had File > Work Offline, which showed you whatever happened to be left in the cache. This page installs a service worker on your first visit. Turn off your wifi and reload: it still opens. The counter and the guestbook go quiet, like a 1999 page with the modem unplugged.

    Made by Elad Sertshuk. No frameworks, no build step, no server. Some things from 1999 were right.

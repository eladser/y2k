    One homepage, rebuilt eight times.

    Halcyon is a made-up airline. Its homepage gets rebuilt the way each year would have done it, with that year's tools and that year's taste. Every version works.

    1. Pick a year on the departures board.
    2. Use the site the way people did then. Search for a flight, sit through the intro.
    3. Press X-ray to see how that version was built, with the real code from that year.
